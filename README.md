## 🧩 Czym się zajmujemy

| Obszar | Co robimy |
|---|---|
| **Wdrożenia enova365** | Analiza przedwdrożeniowa, konfiguracja, migracja danych, szkolenia i start produkcyjny |
| **Dodatki i rozszerzenia** | Własne moduły, workery, akcje, formularze (`form.xml`) i obiekty biznesowe (`business.xml`) |
| **Integracje** | Połączenia z e-commerce, WMS, CRM, KSeF, bankami i systemami zewnętrznymi (API, XML, pliki wymiany) |
| **Wydruki i raporty** | Projektowanie wydruków `.repx`, zestawień i analiz dopasowanych do potrzeb klienta |
| **Kadry i płace** | Konfiguracja elementów wynagrodzeń, algorytmów płacowych i regulaminów czasu pracy |
| **Opieka powdrożeniowa** | Utrzymanie, aktualizacje wersji, helpdesk i rozwój systemu |
